# Assistant Tool Map

Use the source closest to the truth.

## GitHub / Git
Repository files, branches, commits, Actions and current project state.

## Local Python/container
Data migration, ZIP generation, fixtures, schema checks, deduplication, hashes and package tests.

## Web/public sources
Current discographies, release metadata, documentation and other changing public facts. Do not use web search as a substitute for repository truth.

## YouTube/account connector
Use live account/channel tooling for private or current channel state when available. Public search alone is not an authoritative replacement for the user's account inventory.

## Browser / real phone
Interaction, layout, performance, orientation, touch and lifecycle behavior.

## GitHub Actions
CI validation and later application builds.

Never claim a capability was used when it was unavailable.
